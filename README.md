Eat Animal – Prototyp gry w Unity 🐄🎮

"Eat Animal" to prosty prototyp gry stworzony w ramach kursu **Unity Junior Programmer**. Projekt nie jest pełnoprawną grą i nie będzie dalej rozwijany – jego celem było zaprezentowanie podstawowych umiejętności pracy z Unity i C#.

🎥 Demo

Zobacz, jak działa gra:  
https://youtu.be/wn3iLYmolAg

🎮 Na czym polega gra?

Gracz wciela się w farmera, który strzela jedzeniem w nadchodzące zwierzęta.  
Główne zasady:

- Zwierzęta pojawiają się z trzech stron: z przodu, z lewej i z prawej
- Każde zwierzę ma 3 życia – trzeba je trafić kilkukrotnie
- Jeśli zwierzęta dotrą do gracza 3 razy, następuje przegrana – postać nie może się już poruszać
- Celem jest trafienie jak największej liczby zwierząt przed porażką

🧰 Technologia

- Silnik: Unity
- Język: C#
- Wersja WebGL oraz uruchamianie lokalnie z poziomu edytora Unity
- Niektóre funkcje (np. logi debugowania i przegrywanie) działają poprawnie tylko lokalnie – WebGL może mieć problemy z poprawnym wyświetlaniem tych zdarzeń

📦 Uruchamianie

1. Sklonuj repozytorium:
   git clone https://github.com/psujex24/eat_animal_project.git

2. Otwórz projekt w Unity:
   File > Open Project > eat_animal_project

3. Uruchom główną scenę i kliknij Play

Lub zagraj online (WebGL):  
https://play.unity.com/en/games/19f116d0-6a07-4ca8-b1f9-03d7c70840c9/webgl-builds
